# Roadmap and feature matrix

## Stage 1 — source foundation (this repository)
- [x] Native SwiftUI 5-tab shell and dark Kova theme
- [x] Username/password login and age gate (13+)
- [x] Keychain session restoration
- [x] Vertical feed player and labeled sample preview
- [x] API-authenticated like, save, comment, follow and search
- [x] Profiles, edit profile, private accounts, follow requests
- [x] Video choose/record, signed upload, pending content review
- [x] Block and report routes, moderation queue/decision
- [x] Neon schema, backend, documentation and CI
- [ ] Live deployment and iPhone device testing

## Stage 2 — functional beta
- [ ] Video transcoding and HLS adaptive playback
- [ ] Transcription, captions, alt text and improved accessibility
- [ ] Drafts, trimming, filters, duet/stitch editor
- [ ] Recommendation engine (with safety constraints and explainability)
- [ ] Push notifications and notification event generation
- [ ] Follow approvals and privacy/safety QA
- [ ] Secure account recovery / verified contacts / anti-bot
- [ ] Formal moderation policy, human response team, appeals

## Stage 3 — broader community (after full safety work)
- [ ] School/community discovery without sharing user location
- [ ] Teen-appropriate DMs with protections and reporting
- [ ] Video LIVE only if age-gated, staffed moderation and platform policy permit
- [ ] Licensed music, moderation and rights enforcement
- [ ] Detailed analytics, drafts, creator tools and optional website
- [ ] Parent-consented separate restricted under-13 product (not standard social Kova)

No Shop, adult-only features, or age-gate bypasses.
