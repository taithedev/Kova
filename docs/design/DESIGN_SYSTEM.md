# Kova visual language

Dark navy base (`#090A12`), cool lavender action (`#B597FF` approximate), soft aqua highlights, restrained translucent panels, spacious spacing and bold geometric typography. Vertical video is the home screen. Avoid directly copying TikTok branding, icons or layouts; build Kova's own interface.

UI states: guest preview, session authenticated, empty feed, upload pending, failed request, private profile, and moderated content. All demo cards are labeled as previews.
